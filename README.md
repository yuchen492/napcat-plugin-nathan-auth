# napcat-plugin-nathan-auth

🐾 **NapCat Nathan 域名授权管理系统插件**

专为 NapCat / OneBot 11 QQ 机器人与 Nathan 域名授权管理系统打造。提供完整的 WebUI 独立管理面板、QQ 指令交互、卡密批量生成、授权开通、封禁与防刷控制。

---

## 🌟 核心功能

### 1. 现代化独立 WebUI 管理面板
- **📊 仪表盘概览**：实时统计总查询次数、用户卡密自助激活数、管理员手动开通数及批量制卡数。
- **🌐 授权管理与查询**：在线实时核验域名授权、快捷封禁拉黑违规域名、解封与删除授权。
- **🎫 卡密批量生成**：支持自定义生成数量 (1-50)、有效期天数 (0 为永久)、卡密前缀与指定项目 AppID。
- **⚙️ 系统与接口设置**：直观配置 Nathan 站点根地址 (`api_url`)、网站安全密钥 (`web_key`)、管理员账号密码、特权管理员 QQ 列表及生效群号白名单。

### 2. QQ 机器人交互指令

#### 👑 管理员特权指令 (仅 `admin_qqs` 中配置的 QQ 可用)
- `#开通授权 [域名] [QQ] [天数/0为永久] [项目ID]`：快速为站长或客户开通正版授权。
- `#生成卡密 [数量] [天数/0为永久] [项目ID]`：批量自动制卡并在群聊或私聊中导出卡密列表。
- `#封禁授权 [域名] [原因]`：一键拉黑并停用违规域名的授权。
- `#解封授权 [域名]`：解除域名封禁。
- `#删除授权 [域名]`：永久删除该域名的授权记录。
- `#应用列表`：查看后台所有授权项目与单价。

#### 👤 普通用户 / 群成员指令
- `#查授权 [域名]`：在线核验域名是否正版授权。
- `#激活授权 [卡密] [域名]`：购买卡密后自助核销激活，自动绑定当前操作者的 QQ 号。
- `#换绑授权 [旧域名] [新域名]`：原授权 QQ 自助更换授权绑定的域名。
- `#授权帮助`：呼出指令列表。

## 🚀 部署指引

将打包后的 `dist/` 放入 NapCat 插件目录：
```bash
/app/napcat/plugins/napcat-plugin-nathan-auth/
├── index.mjs
├── package.json
├── icon.png
└── webui/
    └── index.html
```
启动 NapCat 后即可在 Web 控制台的插件列表中访问本插件的独立管理面板。
